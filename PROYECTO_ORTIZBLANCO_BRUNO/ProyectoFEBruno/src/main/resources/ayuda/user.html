Gestión de Usuarios

Esta pantalla permite al administrador dar de alta nuevos usuarios, modificar los existentes y eliminarlos. Cada usuario tiene un rol: ADMIN, PROFESOR, TUTOR_EMPRESA o ESTUDIANTE.

Acciones

  • Nuevo: limpia el formulario para introducir un usuario.
  • Guardar: crea o actualiza el usuario seleccionado.
  • Eliminar: elimina el usuario seleccionado en la tabla.
